Rammerhead, but made to run locally (self-hosted) on ngrox, has compatibility to run on other online or self-hosted platforms, but you will need to tweak the index.js and package.json (doesn't work on safari im trying to fix) 

Steps to install (make sure to have git and npm on your computer)
1. Open Windows Command Prompt, type "git clone https://github.com/mamayaya1/rammerhead-ngroks/edit/main/README.md"
2. Then, type "cd rammerhead-ngroks"
3. Finally, run "npm install ", " npm update", and "npm start"

You will need to do these steps for it to run on ngrox 

1. Sign up. Get your Auth Token 
2. Open the .env file and add NGROK_AUTH_TOKEN
